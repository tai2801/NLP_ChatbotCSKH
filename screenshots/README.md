Hướng dẫn chụp màn hình giao diện ứng dụng:
1. Chạy `uvicorn app.main:app --port 8300`, mở http://localhost:8300, bấm nút chat góc phải và thử flow tra đơn `TZ100001` / `0901234567`.
2. Mở http://localhost:8300/admin để chụp dashboard thống kê và quản lý knowledge base.
3. Lưu ảnh vào thư mục này.
